# Senior / BI Analyst 2026 — Mentor ASTRA-2026

Live course: https://ashishjohnexx786-dev.github.io/DA-Mentor-Advance/

A complete senior/BI analyst route: C2_00–C2_09, 122 controlled routes consisting of 114 core units plus 8 optional PL-300 units. Start with **How to study**, then the first C2_00 lesson. The Mentor includes mapped lesson text, instructor/official source assignments, final Astra learner assets, practical routes and optional browser-local progress.

## Study flow

Watch the assigned instructor or official source when one is mapped, understand the written example, do the practical task, save your own attempt and validate the result. Protected reviews are opened only after a genuine saved attempt; repair the weakness, close the review, then complete the changed/fresh retry required by that assessment. Optional PL-300 units are clearly separated from the 114 required core units.

The Mentor records your study decisions and evidence. It does not automatically grade competence and does not replace native Excel, Power Query, Power BI, DAX, Python, Fabric/cloud or other practical execution evidence.

AMOLED and light themes, adjustable reading size and an optional stopwatch are available in Settings. Export progress to transfer between devices; phone and PC do not synchronize automatically. Videos require access to their original provider. Browser-cached pages/assets may remain available offline after they have been visited; large repository/course downloads use the network.

Download the current repository/course package from Settings. Read VERIFICATION.md for static checks and native-runtime limits. No generated video lessons are included.

## Repository layout

- index.html, styles.css, app.js: current Standalone-DE-style Mentor interface.
- curriculum.json and data/: the single current Course 2A curriculum and lesson/companion data.
- COURSE_MODULES/ and current learner assets: final teaching, practice and protected-review material.
- manifest.webmanifest, sw.js: scoped PWA/offline shell.
- icon.svg: current Course 2A Mentor icon.
- release.json: public edition marker.
- VERIFICATION.md: verification scope and remaining native-runtime limits.

The current branch is the active Mentor generation; obsolete legacy UI/state/cache files are not part of the current live tree. Earlier Git commits are repository history, not active Mentor files.

Local progress uses the edition-specific key `course2a-senior-bi-2026-study-astra-v2`. Export a backup before clearing browser data or changing devices.
