# Course 2A Senior / BI Analyst 2026 — Mentor edition Astra 2026

Live course: https://ashishjohnexx786-dev.github.io/DA-Mentor-Advance/

A complete senior-analyst route: C2_00–C2_09, 122 controlled units (114 required) and 10 assessment gates. Start with **How to study**, then continue from the first unfinished lesson. The Mentor is the teaching interface: mapped videos/sources, complete written lesson text extracted from the canonical teaching books, practice links, progress checks and protected review are kept together.

## Study flow

Watch/read the assigned source when mapped, study the complete written lesson in the Mentor, follow the guided example once, do the independent task, save the genuine attempt and only then open protected review. Repair the exact weakness, close the review and retry with changed work. At each gate follow A → Review A → different fresh B → Review B. The Mentor records progression; it does not automatically grade native Excel, Power BI, SQL, Python or cloud work.

AMOLED and light themes, adjustable reading size, roadmap, protected reviews, browser-local progress, export/restore and a detailed How-to-study guide are included. There is no forced timer. Export progress before clearing browser data or changing devices; phone and PC do not synchronize automatically.

Download the complete current repository from Settings. Read VERIFICATION.md for the checks and native-runtime limits. No generated video lessons are included.
