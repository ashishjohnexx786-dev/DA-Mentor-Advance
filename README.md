# DA Mentor Advance

Optional Course 2A companion app for the **Senior / BI Analyst** progression.

## Identity
- Product: **DA Mentor Advance**
- Course role: **Course 2A — Senior / BI Analyst (optional branch)**
- Maintained branch: **main only**
- Interaction model: shared **DE Mentor 2026** study experience; the Course 2A curriculum remains the canonical Senior / BI Analyst curriculum.

## Standard study route
Every core lesson follows the same teacher-like route used across the four Mentor apps:
1. Understand the lesson goal.
2. Learn / read / watch the assigned material.
3. Follow one guided example.
4. Make a genuine independent attempt.
5. Open the protected review only after that attempt.
6. Complete a fresh retry without copying the review.
7. Explain the result aloud in your own words.
8. Mark Mastered only after the fresh retry and explanation are complete.

**Skip for now is not completion.** **I’m stuck** routes the learner into targeted repair.

## Course 2A controls
- 10 phases / 114 core lessons, with PL-300 preparation kept supplementary rather than inflating core mastery.
- Mini-Labs and independent Gates remain separate from lesson completion.
- Gate B/C remain protected retests and are not routine answer sheets.
- Promotion readiness, PL-300 readiness and Data Engineering readiness remain separate evidence signals.
- Manual **START STUDY / END STUDY** tracker uses the real start timestamp; there is no fixed Pomodoro countdown.
- Assigned videos and professional references remain part of the canonical registry.

## Progress and data safety
Progress, notes, repair evidence, reports and backup/restore are stored locally unless explicitly exported. Do not enter confidential employer/customer data, credentials, proprietary code or internal documents.

## PWA / deployment
Static offline-ready PWA for GitHub Pages. The canonical app identity is **DA Mentor Advance** — not the older **DA Mentor Pro** label.
