# DA Mentor Pro

Course 2 companion app: Working Data Analyst → Senior / BI Analyst capability → Data Engineering bridge.

## What it includes
- 10-phase / 114-core-lesson tracker
- exact “What do I do now?” guidance
- practice-review unlock logic
- Mini-Lab and independent Gate controls
- Error & Repair Center
- sanitized Career Evidence Vault
- Promotion Readiness
- PL-300 readiness tracking
- C2-113 Data Engineering readiness / Course 3 lock
- local offline-first progress with backup/restore

## Data safety
Progress is stored in the browser on the user's device. Do not enter confidential workplace/customer data, credentials, proprietary code, or internal documents.
