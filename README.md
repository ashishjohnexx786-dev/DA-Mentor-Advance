# DA Mentor Advance

Optional Course 2A companion app for the **Senior / BI Analyst** progression.

## Course 2A scope
- 10 phases / 114 core lessons
- Learn → Do → Check → Save → Pass workflow
- practice-review unlock logic
- Mini-Lab and independent Gate controls
- Error & Repair Center
- sanitized Career Evidence Vault
- Promotion Readiness
- PL-300 readiness tracking
- C2-113 Data Engineering readiness for the optional 2A branch
- focus timer, daily target, reports, streak, tasks and notes
- JSON backup/restore and CSV export
- seven restrained dark themes, including true AMOLED Black
- offline-first PWA support

## Shared Mentor family

`DA Mentor Launch → DA Mentor Advance (2A optional) / DA Mentor Bridge (2B accelerated) → DA Mentor Engineering`

Advance intentionally keeps the same navigation, study tools and visual language as Launch. It adds senior-analysis, certification-readiness and career-transition controls without forcing the learner to relearn the app.

The visual system is dark, minimalist and lightly dimensional: subtle card depth and hover lift, no heavy neon/glow effects.

## Progress safety
The existing Course 2/2A local progress store remains compatible so the product rename does not intentionally reset learner progress.

## Data safety
Progress is stored in the browser on the user's device. Do not enter confidential workplace/customer data, credentials, proprietary code, or internal documents.

## Deployment
Static offline-first PWA for GitHub Pages.
